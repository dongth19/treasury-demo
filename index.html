Đăng nhập một lần (SSO)

Trình xem hiện tại không chạy JavaScript nên demo không hoạt động.
Trình xem trước file trên iPhone (Tệp, Zalo, Mail) và trong Outlook/Teams không hỗ trợ. Hãy mở file bằng Chrome hoặc Edge trên máy tính, hoặc mở bằng Safari qua đường link http do người trình bày cung cấp.
Chọn tài khoản miền (Active Directory) để đăng nhập
  1. ○ Xác thực mật khẩu với Active Directory
  2. ○ Kiểm tra quyền truy cập hệ thống Treasury
  3. ○ Nạp menu và màn hình theo vai trò

Bản demo dùng dữ liệu mô phỏng, không kết nối AD, Reuters hay T24 thật. Có thể đổi vai trò bất kỳ lúc nào ở thanh trên cùng.
